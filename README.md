# Secure Software Design Project

Coursework for CY-series Secure Software Design, delivered in three stages: security planning, prototype implementation, and a final QR-based attendance system with full SSDLC documentation.

## Deliverable 1 - Planning
- Risk Management Document
- Security Requirements and Planning Document
- Threat Modelling Document

## Deliverable 2 - Prototype
Early prototype web app (admin / student / teacher portals) with a Node.js backend.

## Deliverable 3 - Final: QR Attendance System
A QR-code-based attendance system built with security-by-design principles.

- Source code: Deliverable-3/QR ATTENDANCE SOURCE CODE/
- Docs: SSDLC report, threat model, usage walkthrough, ZAP security scan report
- Reports: Final report, slide deck, risk management and threat modelling documents

### Running the Deliverable 3 app
```powershell
cd "Deliverable-3/QR ATTENDANCE SOURCE CODE"
npm install
copy .env.example .env
npm start
```
